# Sample Kit

A dependency-free Python reference implementation for data, weighted-sampling, metrics.

Run with: python3 demo.py
Tests: python3 -m unittest discover -s tests -v

## Scope

实现可复现的加权无放回采样与指标序列化工具。相同种子和输入必须得到相同序列；零权重、负权重、重复项和空有效样本必须按公开规则处理；指标输出中的超大整数始终保持精确十进制，不能经过浮点转换。公开函数、参数校验和异常类型应当可由独立数值脚本直接验证。

单轮排除入口：`weighted_sample_excluding_indices(items, weights, k, excluded=(), seed=0)` 在完成与现有采样入口一致的校验后，按集合语义排除 `excluded` 中的原始零基位置（重复与排列顺序不影响结果），再在剩余位置中按权重比例无放回抽取 `k` 个不同位置并返回原始索引；`weighted_sample_excluding` 按相同索引返回元素值。被排除位置即使权重为正也绝不出现，未排除的零权重仍永不入选；`excluded` 为空时与现有单轮入口逐项相同。`excluded` 结构或成员类型错误抛 TypeError，越界位置、有效正权重不足等抛 ValueError，全部校验在产生任何结果前完成。

排除位置的批量/流式入口：`weighted_sample_many_excluding_indices(items, weights, k, excluded, draws, seed=0, start=0)` 一次生成 `draws` 轮排除后的无放回样本（每轮返回按抽样先后排列的原始零基索引，外层长度等于 `draws`），`weighted_sample_many_excluding` 按相同索引返回元素值；`weighted_sample_stream_excluding_indices` / `weighted_sample_stream_excluding` 是对应的按需逐轮入口。每轮都从同一组未排除位置重新开始（轮内不放回，轮间恢复全部未排除位置），所有轮次共享由 `seed` 初始化的同一条随机流；`start` 只跳过前面的完整轮次，结果与 `start=0` 的完整调用按区间 `[start, start+draws)` 切片逐项一致。`start=0` 首轮逐项等于单轮排除入口，`excluded` 为空时与 `weighted_sample_many(_indices)` / `weighted_sample_stream(_indices)` 逐轮一致。校验顺序固定为 items/weights/k/seed → excluded → draws → start，再在输出任何一轮前完成未排除位置的正权重可行性检查；流式入口虽按需产出，但全部参数与可行性错误都在创建时抛出。`draws=0` 返回空结果；`k=0` 时每轮为空且跳过轮次不消耗随机流；索引轮次可直接交给 `serialize_metrics` 精确序列化。

批量频次入口：`weighted_sample_counts(items, weights, k, draws, seed=0, start=0)` 与 `weighted_sample_excluding_counts(items, weights, k, excluded, draws, seed=0, start=0)` 以原始零基位置为统计单位，免去调用方逐轮遍历。两者接受与对应批量索引入口相同的参数、`start` 窗口语义与固定校验顺序（排除入口共享 `excluded` 的集合语义），按同一随机流生成窗口内的轮次，返回长度等于 `items` 的整数列表 `counts`，`counts[i]` 即区间 `[start, start+draws)` 中位置 `i` 被选中的次数；结果等于把对应索引入口同窗口的全部轮次按位置摊平计数，首轮、后续轮次、相同种子及 `k=0` 的随机流消耗逐项对齐。被排除位置的计数始终为零，其余位置按每轮重新开始的未排除位置池累计，重复元素值仍视为不同位置。`draws=0` 或 `k=0` 返回全零列表但仍完成全部校验；正权重不足在返回列表前抛 ValueError，任何失败都不给出部分计数，也不修改输入序列或 `excluded`。计数为任意精度整数，可直接交给 `serialize_metrics`，经 `serialize_metrics` / `deserialize_metrics` 往返后仍是相同的整数列表（不转浮点或科学计数文本）。

按轮次变化权重的批量入口：`weighted_sample_schedule_indices(items, weights_schedule, k, draws, seed=0, start=0)` 与 `weighted_sample_schedule(items, weights_schedule, k, draws, seed=0, start=0)` 接受有限非文本序列 `weights_schedule`，其成员均为与 `items` 等长的权重序列；第 `start+j` 轮使用 `weights_schedule[start+j]`，返回 `draws` 轮（索引入口给出原始零基位置，值入口按位置映射 `items`，两入口逐轮逐项对应）。`weighted_sample_schedule_counts(items, weights_schedule, k, draws, seed=0, start=0)` 是对应的批量频次入口，接受相同参数、`start` 窗口语义与固定校验顺序，按同一随机流（每轮同一权重行与同一抽样计划）累计窗口内选中次数，返回长度等于 `items` 的整数列表，`counts[i]` 即区间 `[start, start+draws)` 中位置 `i` 被选中的次数，结果等于把 `weighted_sample_schedule_indices` 对应窗口的全部轮次按位置摊平计数；`draws=0` 或 `k=0` 返回全零列表但仍完成全部校验（`k=0` 不消耗随机流），任何失败都不给出部分计数，计数为任意精度整数并可经 `serialize_metrics` / `deserialize_metrics` 精确往返。每轮从全部位置重新开始，轮内无放回，重复值按位置区分；所有轮共享由 `seed` 初始化的一条随机流，`start` 只跳过完整轮次并消耗与从 0 生成时相同的随机流（被跳过的第 j 轮同样按 `weights_schedule[j]` 的权重与抽样计划消耗），`k=0` 的轮次返回空列表且不消耗随机流。`start=0` 的首轮与 `weighted_sample_indices` 对应行逐项一致；权重各行相同则与 `weighted_sample_many_indices` 同参完全一致。全部校验在返回任何轮次前完成：`items`、`k`、`seed` 沿用现有入口规则，`draws`/`start` 为非布尔非负整数；`schedule` 非长度可确定非文本序列或任一行非同类序列时抛 TypeError，行长度不等于 `items`、窗口超出 `schedule` 范围、负权重、NaN、无穷权重或任一行在 `k>0` 时正权重位置不足 `k` 个时抛 ValueError；权重元素继续接受非布尔 int、有限非负 float、Fraction 和 Decimal，超大整数、Fraction、Decimal 不转成浮点。`draws=0` 仍完成全部结构、权重和可行性校验并返回空列表；输入序列及 `schedule` 均不被修改，返回的普通索引或值列表可直接交给 `serialize_metrics`。

按轮次变化权重同样支持按需逐轮入口：`weighted_sample_schedule_stream_indices(items, weights_schedule, k, draws, seed=0, start=0)` 返回一个可迭代对象，调用方逐轮取得与 `weighted_sample_schedule_indices` 完全一致的零基原始索引列表，`weighted_sample_schedule_stream` 按相同索引逐轮映射 `items` 元素；相同 `items`、`weights_schedule`、`k`、`seed`、`start`、`draws` 下，流式物化结果与对应批量入口逐项一致，`start` 只在迭代时按需跳过前面的完整轮次（被跳过轮次同样按其权重行与抽样计划消耗同一条随机流），不改变后续随机序列。每轮位置不重复，轮次之间允许再次选中同一位置，零权重永不被选中。全部参数与可行性校验（`items`、`weights_schedule` 及每个权重行必须是可确定长度的非文本序列、行长等于 `items`；`k`、`draws`、`start` 为非布尔非负整数且 `k` 不超过 `items` 长度；`start+draws` 不超过计划长度；权重接受 int/float/Fraction/Decimal 并拒绝负数、NaN、无穷；任一轮正权重不足以满足 `k` 时抛 ValueError）都在迭代器返回前完成并当场抛出，结构或类型不符抛 TypeError，`draws=0` 或 `k=0` 也不省略校验；`draws=0` 返回不产出元素的可迭代对象，`k=0` 时每轮产出空列表且不消耗随机流。流式调用不修改 `items`、`weights_schedule` 或其中的行，重复元素仍按原始位置区分，Decimal、Fraction 及超大整数权重保持既有可复现序列，迭代器使用方式与固定权重流式入口一致，逐轮结果可直接交给 `serialize_metrics` 并经 `deserialize_metrics` 无损还原。

固定排除集合与按轮权重计划的组合入口：`weighted_sample_excluding_schedule_indices(items, weights_schedule, k, excluded, draws, seed=0, start=0)` 与 `weighted_sample_excluding_schedule(items, weights_schedule, k, excluded, draws, seed=0, start=0)` 把"按原始零基位置排除"与"每轮使用 `weights_schedule` 对应行"组合在一起：第 `start+j` 轮使用 `weights_schedule[start+j]`，每轮都从同一组未排除位置（原始零基位置中剔除 `excluded` 后保留的位置）重新开始，轮内按该行权重无放回抽取 `k` 个不同位置（索引入口给出原始零基位置，值入口按位置映射 `items`，两入口逐轮逐项对应，重复值仍按位置区分）。被排除位置即使权重为正也绝不出现，未排除的零权重位置仍永不入选；`excluded` 按集合语义解释（重复成员与排列顺序不影响结果）。`weighted_sample_excluding_schedule_counts` 是对应的批量频次入口，返回长度等于 `items` 的整数列表，`counts[i]` 即区间 `[start, start+draws)` 中位置 `i` 被选中的次数，被排除位置始终为零，结果等于把索引入口同窗口的全部轮次按位置摊平计数；`weighted_sample_excluding_schedule_stream_indices` / `weighted_sample_excluding_schedule_stream` 是对应的按需逐轮入口，创建时完成全部校验且逐轮与批量入口一致。所有轮次共享由 `seed` 初始化的一条随机流，`start` 只跳过前面的完整轮次（被跳过的第 j 轮同样按 `weights_schedule[j]` 的权重与抽样计划消耗该流），`k=0` 的轮次返回空列表且不消耗随机流；`start=0` 的首轮与 `weighted_sample_excluding_indices` 对应行逐项一致，`excluded` 为空时与 `weighted_sample_schedule(_indices)` 同参逐轮一致，各行权重完全相同时与 `weighted_sample_many_excluding(_indices)` 同参一致。校验顺序固定为 items、weights_schedule、k、seed、excluded、draws、start，然后检查行长度、窗口范围、权重取值和每一行未排除位置的正权重数量：结构、成员、seed、draws 或 start 类型错误抛 TypeError，负数、越界、长度或可行性错误抛 ValueError，全部校验在返回任何轮次前完成（`draws=0` 也不例外，返回空轮次或全零计数），任何失败都不产生部分结果，输入与 `excluded` 均不被修改。计数为任意精度整数，可直接交给 `serialize_metrics` 并经 `deserialize_metrics` 精确往返；单轮、普通计划和固定排除入口及其异常行为保持不变。

按轮权重计划同样支持可暂停/恢复：`weighted_sample_schedule_checkpoint(items, weights_schedule, k, seed=0, start=0)` 沿用现有 schedule 规则完成 `items`、`weights_schedule`、`k`、`seed`、`start` 的全部校验(有限非文本序列、行长度与 `items` 相同，权重接受非布尔 int、有限非负 float、Fraction、Decimal，负数、NaN、无穷、错误结构或 `k` 个正权重不足都被拒绝，`start` 越过计划长度抛 ValueError)，跳过 `start` 个完整轮次后返回只含 JSON 原生值的状态映射(版本、kind、当前 position、k/n、计划长度、items 指纹、完整 schedule 指纹、标签化 seed、随机流快照与绑定摘要)。`weighted_sample_schedule_resume_indices(items, weights_schedule, k, state, draws)` 从断点起返回 `(索引轮次, 下一状态)`，逐轮等于一次性 `weighted_sample_schedule_indices` 的零基区间 `[position, position+draws)`，连续恢复与一次性调用逐项一致，恢复无需从头重放随机流；`weighted_sample_schedule_resume(items, weights_schedule, k, state, draws)` 按原始位置映射 `items` 元素(重复值仍按位置区分)，下一状态与索引入口逐字段一致、可互换续接。`draws=0` 返回空轮次与不变的状态副本，`k=0` 只推进 position 而不消耗随机流；`draws` 不是非布尔非负整数或恢复窗口超出计划范围分别抛 TypeError/ValueError，状态非映射抛 TypeError，字段缺失或未知、版本不支持、摘要或输入(items、完整 schedule、k)不匹配统一抛 ValueError，且全部失败都不产生部分轮次也不修改输入。状态经 `serialize_metrics` / `deserialize_metrics` 往返后仍可恢复，RNG 等超大整数保持精确十进制。

权重与样本数同时按轮变化的联合计划：`weighted_sample_plan_indices(items, weights_schedule, k_schedule, draws, seed=0, start=0)` 与 `weighted_sample_plan(items, weights_schedule, k_schedule, draws, seed=0, start=0)` 接受等长的两个有限非文本序列计划，第 `start+j` 轮同时使用 `weights_schedule[start+j]` 的权重行与 `k_schedule[start+j]` 的样本数在位置中按权重无放回抽样（索引入口给出原始零基位置，值入口按位置映射 `items`，两入口逐轮逐项对应）；`weighted_sample_plan_counts(items, weights_schedule, k_schedule, draws, seed=0, start=0)` 是对应的批量频次入口，返回长度等于 `items` 的整数列表，`counts[i]` 即区间 `[start, start+draws)` 中位置 `i` 被选中的次数，结果等于把 `weighted_sample_plan_indices` 对应窗口的全部轮次按位置摊平计数。每轮从全部位置重新开始，轮内无放回，重复值按位置区分，轮间恢复全部位置；所有轮共享由 `seed` 初始化的一条随机流，`start` 只跳过完整轮次并消耗与从 0 生成时相同的随机流（被跳过的第 j 轮按 `weights_schedule[j]` 与 `k_schedule[j]` 消耗），样本数为零的轮次返回空列表且不消耗随机流；权重各行相同且计划各项都等于 `k` 时与 `weighted_sample_many_indices` 同参完全一致。全部校验在返回任何轮次前完成：`items`、两个计划及每行均为可确定长度的非文本序列，两个计划等长且权重行等于 `items` 长度，`k_schedule` 成员、`draws`、`start` 为非布尔非负整数且成员不超过位置数；结构或成员类型错误抛 TypeError，长度、窗口、越界或负数抛 ValueError；所有行校验权重（非布尔 int、有限 float、Fraction、Decimal，可混合），负数、NaN、无穷或对应轮正权重不足抛 ValueError。`draws=0` 仍完成全部校验并返回空结果，任何失败都不产生部分结果也不修改输入，计数为任意精度整数并可经 `serialize_metrics` / `deserialize_metrics` 精确往返。

联合计划同样支持可暂停/恢复：`weighted_sample_plan_checkpoint(items, weights_schedule, k_schedule, seed=0, start=0)` 沿用联合计划批量入口的全部校验（`start` 越过计划长度抛 ValueError），跳过 `start` 个完整轮次后返回只含 JSON 原生值的状态映射（版本、kind、当前 position、n、计划长度、items / 完整 weights_schedule / 完整 k_schedule 指纹、标签化 seed、随机流快照与绑定摘要）；`weighted_sample_plan_resume_indices(items, weights_schedule, k_schedule, state, draws)` 从断点起返回 `(索引轮次, 下一状态)`，逐轮等于一次性 `weighted_sample_plan_indices` 的零基区间 `[position, position+draws)`，连续恢复与一次性调用逐项一致，恢复无需从头重放随机流；`weighted_sample_plan_resume(items, weights_schedule, k_schedule, state, draws)` 按原始位置映射元素值，下一状态与索引入口逐字段一致、可互换续接。`draws=0` 返回空轮次与不变的状态副本，样本数为零的轮次只推进 position 而不消耗随机流；`draws` 类型错误抛 TypeError、负值或恢复窗口越界抛 ValueError，状态非映射抛 TypeError，字段缺失或额外、版本或 kind 不支持、摘要或输入不匹配统一抛 ValueError，且全部失败都不产生部分轮次也不修改输入。状态经 `serialize_metrics` / `deserialize_metrics` 往返后仍可恢复，RNG 等超大整数保持精确十进制。

长批次支持可暂停/恢复的采样会话：`weighted_sample_checkpoint(items, weights, k, seed=0, start=0)` 返回只含 JSON 原生值(版本、当前位置、items/weights 指纹、标签化 seed、RNG 快照与绑定摘要)的状态映射，可直接交给 `serialize_metrics` 或落盘；`weighted_sample_resume_indices(items, weights, k, state, draws)` 从断点续接，返回 `(索引轮次, 下一状态)`，逐轮等于批量入口的对应零基区间，恢复时无需从头重放随机流；`weighted_sample_resume(items, weights, k, state, draws)` 为按元素值恢复入口，每轮返回与索引轮次逐项对应的元素值列表(相同值的不同位置分别消耗)，下一状态与按索引入口完全相同、可互换续接。

排除采样同样支持可暂停/恢复：`weighted_sample_excluding_checkpoint(items, weights, k, excluded, seed=0, start=0)` 沿用 items/weights/k/seed/start 校验并按集合语义处理 `excluded`(重复位置与排列顺序不影响结果)，先完成 `start` 个轮次再返回当前位置与只含 JSON 原生值的状态(绑定版本、位置、k/n、规范化 excluded、items/weights 指纹、标签化 seed、RNG 快照与抽样计划)；`weighted_sample_excluding_resume_indices(items, weights, k, excluded, state, draws)` 返回 `(索引轮次, 下一状态)`，逐轮等于 `weighted_sample_many_excluding_indices` 从断点位置起的零基区间，多次续接与一次性生成逐项相同，`excluded` 为空时与普通恢复入口一致；`weighted_sample_excluding_resume(items, weights, k, excluded, state, draws)` 按原始位置映射元素值，下一状态与按索引入口逐字段一致。`draws=0` 返回空轮次与不变的状态副本，`k=0` 时生成 `draws` 个空轮次、只推进位置且不耗随机流；状态可经 `serialize_metrics` / `deserialize_metrics` 往返后继续恢复，字段缺失或额外、版本不支持、摘要或输入不匹配统一抛 ValueError 且不产生部分轮次，非映射状态抛 TypeError。

分组采样把一次无放回加权序列切成多个互不重叠的样本组，支持计划分段消费：`weighted_sample_partition_indices(items, weights, group_sizes, seed=0)` 对 `(items, weights)` 做一次长度为 `sum(group_sizes)` 的加权无放回抽样，再按 `group_sizes` 切片，返回按组排列的零基原始位置(组内与组间位置都不重复)；`weighted_sample_partition(items, weights, group_sizes, seed=0)` 按原始位置映射 `items` 元素，两入口逐组逐项对应。`items`、`weights` 沿用现有入口规则(等长的有限非文本序列、int/float/Fraction/Decimal 权重、相同 seed 规则)，`group_sizes` 是有限非文本序列、成员为非布尔非负整数；依次拼接各组逐项等于 `weighted_sample_indices(items, weights, sum(group_sizes), seed)` 按 `group_sizes` 切片，零权重位置永不出现。结构或成员类型错误抛 TypeError，长度不一致、负组大小、总组大小超过可用正权重位置数、负权重、NaN 或无穷权重抛 ValueError；空计划、全零组大小及权重总量为零在校验后返回对应数量的空组，输入不被修改。

分组采样同样支持可暂停/恢复：`weighted_sample_partition_checkpoint(items, weights, group_sizes, seed=0, start=0)` 沿用分组入口的全部校验，`start` 为非布尔非负整数且不超过组计划长度，校验后一次性抽出整条无放回位置序列并以 `start` 标记组边界，返回只含 JSON 原生值的状态(绑定版本、kind、start、n、组数与总组大小、items/weights/group_sizes 指纹、标签化 seed、抽样计划、整条组位置序列与摘要)；`weighted_sample_partition_resume_indices(items, weights, group_sizes, state, draws)` 返回 `(索引分组, 下一状态)`，逐组等于一次性 `weighted_sample_partition_indices` 的零基区间 `[start, start+draws)`，多次续接与一次性生成逐项一致，恢复按状态携带的序列切片、无需重放随机流；`weighted_sample_partition_resume(items, weights, group_sizes, state, draws)` 按原始位置映射元素值，下一状态与按索引入口逐字段一致、可互换续接。`draws=0` 返回空分组与不变的状态副本，越过计划范围抛 ValueError；非映射状态抛 TypeError，字段缺失或未知、版本不支持、摘要或绑定不匹配统一抛 ValueError 且不产生部分分组。状态经 `serialize_metrics` / `deserialize_metrics` 往返后仍可恢复，既有结果与异常语义保持不变。

分组结果还支持按需消费与频次统计：`weighted_sample_partition_stream_indices(items, weights, group_sizes, draws, seed=0, start=0)` 返回一个可迭代对象，每次迭代产出一个组的零基原始索引列表，共 `draws` 个，外层第 j 个列表即完整组计划中编号 `start+j` 的组；`weighted_sample_partition_stream` 按相同索引逐组映射 `items` 元素(重复值仍按位置区分)。两个流式入口与一次性分组及断点恢复共享同一条由一次加权无放回抽样产生的位置序列，`start` 只选择该序列上的组边界窗口、不改变序列本身，因此同一窗口 `[start, start+draws)` 的结果逐组逐项一致，组内组间位置都不重复，零权重位置永不出现。`weighted_sample_partition_counts(items, weights, group_sizes, draws, seed=0, start=0)` 返回长度等于 `items` 的整数列表，`counts[i]` 即组窗口 `[start, start+draws)` 中位置 `i` 被选中的次数，等于把流式索引入口同窗口的全部组按位置摊平计数；计数为任意精度普通整数，可直接交给 `serialize_metrics` 并经 `deserialize_metrics` 精确往返，全程不经过浮点。三个入口沿用分组入口的固定校验顺序与异常类别：创建时先完成 items、weights、seed、group_sizes 的结构、成员类型、长度、权重取值与完整计划的正权重可行性校验，再要求 `draws`、`start` 为非布尔非负整数且窗口不越过组计划(计划末尾只接受空窗口)；结构或成员类型错误抛 TypeError，长度不一致、负组大小、非法权重、正权重不足或窗口越界抛 ValueError。`draws=0` 仍完成全部校验并返回空迭代器或全零列表，空 `items` 只有全零组计划时成功；任何失败都不产生部分结果，输入不被修改。

分层配额采样按分层编号把位置分组、逐层按配额抽样：`weighted_sample_stratified_indices(items, weights, strata, quotas, seed=0)` 中 `strata` 与 `items` 等长、每个位置保存非布尔非负整数分层编号，`quotas` 的下标对应分层编号、成员为非布尔非负整数配额且长度必须恰好等于最大编号加一；分层按编号升序依次处理，第 number 层在其成员位置中按权重比例无放回抽取 `quotas[number]` 个不同位置，各层结果按编号升序拼接、层内按抽样先后排列，返回原始零基索引。`weighted_sample_stratified` 按相同索引映射元素值(重复值仍按位置区分)，`weighted_sample_stratified_counts` 返回长度等于 `items` 的整数列表(选中位置为一、其余为零)，与索引入口按位置统计相同，可直接交给 `serialize_metrics` 并经 `deserialize_metrics` 精确往返。所有层共享同一个由 `seed` 初始化的随机流，零配额分层不消耗该流；相同输入、配额和 `seed` 逐项相同，只有编号为零的单层时与 `weighted_sample_indices` / `weighted_sample` 完全一致。校验顺序固定为 items、weights、seed、strata、quotas、长度和编号范围、权重取值、每层正权重可行性：`strata` 与 `quotas` 必须是非文本且长度可确定的序列、成员必须是非布尔非负整数，结构或成员类型错误抛 TypeError；`strata` 长度不等于 `items`、`quotas` 长度不是最大编号加一、编号越界、负配额、配额超过该层正权重位置数抛 ValueError；负权重、NaN、无穷权重按既有规则处理，零权重永不入选。空 `items` 只接受空 `strata` 和 `quotas`，全部配额为零时返回空层结果；全部校验在输出前完成，输入不被修改。

按轮变化的分层配额计划：`weighted_sample_stratified_schedule_indices(items, weights, strata, quotas_schedule, draws, seed=0, start=0)` 与 `weighted_sample_stratified_schedule` 接受可确定长度的非文本序列 `quotas_schedule`，其每个成员都是长度等于最大分层编号加一的配额行(非文本且长度可确定的序列，成员为非布尔非负整数)；第 `start+j` 轮使用 `quotas_schedule[start+j]`，按该行配额逐层做加权无放回抽样、各层结果按分层编号升序拼接作为该轮结果，返回长度等于 `draws` 的外层列表(索引入口给出原始零基位置，值入口按原始索引映射 `items`，重复值仍按位置区分)。`weighted_sample_stratified_schedule_counts` 返回长度等于 `items` 的整数列表，`counts[i]` 即区间 `[start, start+draws)` 中位置 `i` 被选中的次数，等于把索引入口同窗口的全部轮次按位置摊平计数；`weighted_sample_stratified_schedule_stream_indices` / `weighted_sample_stratified_schedule_stream` 是对应的按需逐轮入口，创建时完成全部校验且逐轮与批量入口一致。每轮从全部位置重新开始(轮内各层无放回，轮间恢复全部位置)；所有轮次与轮内各层共享由 `seed` 初始化的一条随机流，`start` 跳过的轮次仍按各自配额行消耗该流，零配额分层不消耗。权重继续接受非布尔 int、有限 float、Fraction、Decimal 及其混合，超大整数、Fraction、Decimal 全程不经过浮点。空 `items` 时 `strata` 与每行配额都须为空；`draws=0` 仍校验完整计划、每行可行性与窗口并返回空结果。序列结构或成员类型错误抛 TypeError；长度不一致、编号越界、行长不等于最大编号加一、负配额、窗口超界、负权重、NaN、无穷权重或任一行某层正权重不足配额抛 ValueError；全部校验在输出任何轮次前完成，输入不被修改，计数为任意精度整数并可经 `serialize_metrics` / `deserialize_metrics` 精确往返。

按轮分层计划同样支持可暂停/恢复：`weighted_sample_stratified_schedule_checkpoint(items, weights, strata, quotas_schedule, seed=0, start=0)` 沿用批量入口的全部校验(`start` 越过计划长度抛 ValueError)，跳过 `start` 个完整轮次后返回只含 JSON 原生值的状态映射(版本、kind、当前 position、n、分层数、计划长度、items / weights / strata / 完整 quotas_schedule 指纹、标签化 seed、逐轮逐层抽样路径标记、随机流快照与完整性摘要)；`weighted_sample_stratified_schedule_resume_indices(items, weights, strata, quotas_schedule, state, draws)` 从断点起返回 `(索引轮次, 下一状态)`，逐轮等于一次性 `weighted_sample_stratified_schedule_indices` 的零基区间 `[position, position+draws)`，连续恢复与一次性调用逐项一致，恢复无需从头重放随机流；`weighted_sample_stratified_schedule_resume` 按原始位置映射元素值，下一状态与索引入口逐字段一致、可互换续接。`draws=0` 返回空轮次与不变的状态副本，零配额分层只推进位置而不消耗随机流；`draws` 只能是非布尔非负整数，类型错误抛 TypeError、负值或恢复窗口越界抛 ValueError，状态非映射抛 TypeError，字段缺失或额外、版本或 kind 不支持、摘要或输入不匹配统一抛 ValueError，且全部失败都不产生部分轮次也不修改输入。状态经 `serialize_metrics` / `deserialize_metrics` 往返后仍可恢复，RNG 等超大整数保持精确十进制；固定配额入口行为保持不变。

分层配额与位置排除可以组合：`weighted_sample_stratified_excluding_indices(items, weights, strata, quotas, excluded=(), seed=0)` 在分层配额规则之上再按集合语义排除 `excluded` 中的原始零基位置(重复成员与排列顺序不影响结果)——每层按编号升序处理，只在该层且未被排除的位置中按 `weights` 比例无放回抽取 `quotas[number]` 个原始零基位置，各层结果按编号升序拼接、层内按抽样先后排列；`weighted_sample_stratified_excluding` 按相同索引映射元素值(重复值仍按位置区分)。被排除位置即使权重为正也绝不出现，未排除的零权重位置仍永不入选；所有层共享同一个由 `seed` 初始化的随机流，零配额分层不消耗该流；`excluded` 为空时与 `weighted_sample_stratified_indices` / `weighted_sample_stratified` 逐项相同。`weighted_sample_stratified_excluding_stream_indices` / `weighted_sample_stratified_excluding_stream` 是对应的按需逐轮入口(增加 `draws`、`seed`、`start`)：每轮恢复同一组未排除位置，轮间共享同一条随机流，`start` 只跳过完整轮次，结果与 `start=0` 的完整序列按区间 `[start, start+draws)` 切片逐轮一致，`start=0` 首轮逐项等于一次性入口。`weighted_sample_stratified_excluding_counts(items, weights, strata, quotas, excluded, draws, seed=0, start=0)` 返回长度等于 `items` 的整数列表，统计窗口内各原始位置的选中次数，排除位置始终为零，与流式索引入口逐轮摊平一致，可经 `serialize_metrics` / `deserialize_metrics` 精确往返。校验顺序固定为 items、weights、seed、strata、quotas、长度和编号范围、权重取值、excluded、draws、start，再做排除后逐层配额的正权重可行性检查：结构或成员类型错误(含 `excluded` 成员)抛 TypeError，长度不一致、编号或 `excluded` 位置越界、负配额、负数或非有限权重、排除后某层正权重不足配额抛 ValueError；`draws=0` 仍完成全部校验并返回空轮次或全零计数，任何失败都不产生部分结果，也不修改输入。

固定配额的"分层配额 + 位置排除"同样支持可暂停/恢复：`weighted_sample_stratified_excluding_checkpoint(items, weights, strata, quotas, excluded=(), seed=0, start=0)` 沿用一次性组合入口的全部校验与固定顺序(items、weights、seed、strata、quotas、长度与编号范围、权重取值、excluded，再做排除后逐层配额的正权重可行性检查)，`start` 为非布尔非负整数且不超过分层数(`start == 分层数` 允许)，按编号升序处理完前 `start` 个分层后返回只含 JSON 原生值的状态映射(版本、kind="stratified_excluding"、当前 position、n、分层数、按原始位置升序去重规范化的 excluded、items / weights / strata / quotas 指纹、标签化 seed、逐层抽样路径标记、随机流快照与绑定摘要)，生成状态前完成全部校验、失败不产生部分结果，也不修改入参与 `excluded`。`weighted_sample_stratified_excluding_resume_indices(items, weights, strata, quotas, excluded, state, draws)` 从断点的 position(已完成的分层前缀)起消费 `draws` 个分层，按分层编号拼接原始零基位置并返回 `(索引列表, 下一状态)`；相同参数与种子下，分段结果必须等于一次性 `weighted_sample_stratified_excluding_indices` 完整结果按分层边界切片，多次续接与一次性生成逐项相同，恢复时从随机流快照续接、无需从头重放。`weighted_sample_stratified_excluding_resume(items, weights, strata, quotas, excluded, state, draws)` 按原始位置映射 `items` 元素值(重复值仍按位置区分)，与索引入口逐位置对应、下一状态完全相同。`draws` 是非布尔非负整数(布尔与其他类型抛 TypeError、负数抛 ValueError)，窗口越过 quotas 长度抛 ValueError、计划末尾只接受空窗口；`draws=0` 返回空结果与状态副本，零配额(含无成员)分层只推进 position 且不消耗 RNG。恢复前校验状态版本、kind(跨种类状态拒绝)、字段集合、绑定摘要、RNG 与输入指纹(items、weights、strata、quotas、excluded 集合)，篡改或任何不匹配统一抛 ValueError、不泄露底层异常；状态非映射抛 TypeError，输入本身的错误沿用组合入口的 TypeError / ValueError(值入口先完成输入校验再解析状态)，全部失败都不产生部分结果，也不修改输入或状态。状态经 `serialize_metrics` / `deserialize_metrics` 或标准 JSON 往返后仍恢复出同一序列，整数、浮点、Fraction、Decimal 与超大整数权重的精确路径逐层保留，RNG 等超大整数始终保持精确十进制；`excluded` 为空时与无排除分层断点恢复的对应窗口逐项一致，既有采样、流式、计数与其他 checkpoint/resume 入口的行为与异常类型保持不变。

两种组合规则可以再合并：`weighted_sample_stratified_excluding_schedule_indices(items, weights, strata, quotas_schedule, excluded, draws, seed=0, start=0)` 与 `weighted_sample_stratified_excluding_schedule` 把"位置排除"叠加到"按轮变化的分层配额计划"上——第 `start+j` 轮使用 `quotas_schedule[start+j]`，每轮从所有未排除位置重新开始，按分层编号递增、层内按权重无放回抽取并拼接该轮的原始零基索引(值入口按索引映射 `items`，重复值按位置区分)；`weighted_sample_stratified_excluding_schedule_stream_indices` / `weighted_sample_stratified_excluding_schedule_stream` 是对应的按需逐轮入口，创建时完成全部校验；`weighted_sample_stratified_excluding_schedule_counts` 返回长度等于 `items` 的整数列表，`counts[i]` 即窗口 `[start, start+draws)` 内位置 `i` 的选中次数，排除位置始终为零。相同输入和 `seed` 得到相同序列，`start` 只跳过随机流的前置轮次(被跳过的轮次仍按各自配额行消耗同一条流)，窗口等于完整序列切片；零配额轮次返回空列表且不耗随机流，`draws=0` 在完整校验后返回空结果或全零计数。`excluded` 按 `items` 位置去重解释(重复成员与排列顺序不影响结果)，排除位置与零权重位置永不出现；权重继续接受非布尔 int、有限 float、Fraction、Decimal 及其混合，超大整数与极小正数走精确路径、不因浮点转换改变结果。`excluded` 为空时与 `weighted_sample_stratified_schedule_*` 各入口逐项一致，单行计划 `[quotas]` 的首轮与 `weighted_sample_stratified_excluding_indices` 逐项一致。校验顺序固定为 items、weights、seed、strata、quotas_schedule、draws、start、长度和编号范围与窗口、权重取值、excluded，再对完整计划的每一行做排除后逐层配额的正权重可行性检查：结构或成员类型错误抛 TypeError，长度不一致、编号或 `excluded` 位置越界、行长不等于最大编号加一、负配额、窗口越界、非法权重、排除后某层正权重不足配额抛 ValueError；全部校验在产出前完成，失败不返回部分结果也不修改输入，计数为任意精度整数并可经 `serialize_metrics` / `deserialize_metrics` 精确往返。

`deserialize_metrics(text)` 是 `serialize_metrics` 的逆入口：把指标序列化文本还原为可继续计算的 Python 数据树(null/布尔/字符串/数组/对象分别还原为 None/bool/str/list/dict，对象成员名保持文本形式与次序)。数字解析完全绕开浮点：无小数点或指数标记的数字还原为任意精度 int，带小数点或指数标记的有限数字还原为 Decimal(保留正负号、刻度、指数与负零)；超长整数与极端指数在解释器整数转文本限制较低时仍精确成功。NaN/Infinity/-Infinity、语法错误、重复对象成员名及无法保持精度的数字统一抛 ValueError，非 str 输入抛 TypeError。还原后的数据可直接再交给 `serialize_metrics`(整数与 Decimal 的十进制内容保持精确)，也可直接消费 checkpoint 状态文本并交给恢复入口续接。
